# EPD-nRF5 项目详细汇总分析

## 1. 项目概况与定位
**EPD-nRF5** 是一个专门为电子墨水屏（e-paper display）设计的日历固件项目，主要基于 Nordic Semiconductor 的低功耗蓝牙芯片（如 nRF51822 / nRF52811 等）开发。通过该固件可以实现以下主要应用场景：
- **墨水屏日历**：展示中国农历、节气、节假日、调休安排。
- **数字相框**：支持通过蓝牙（Web Bluetooth 接口）将图片数据从手机/PC端直接推送到墨水屏进行显示。
- **动态设备适配**：固件支持常见的墨水屏分辨率（如 4.2 英寸和 7.5 英寸等），支持包含黑白、三色、四色的普遍 `UC81xx` / `SSD16xx` 系列驱动板。同时支持在线（网页端）切换屏幕尺寸和修改墨水屏与 MCU 之间的针脚映射。

## 2. 核心架构与目录结构解析

整个项目的根目录结构按功能模块划分得较为清晰：

### 2.1 固件主程序
- **[main.c](file:///e:/EPD-nRF5/main.c) / [main.h](file:///e:/EPD-nRF5/main.h)**
  - **核心入口**：包含了 nRF5 设备初始化，如软设备（SoftDevice）和硬件外设设置（看门狗、时钟/定时器）。
  - **电源与事件调度**：利用 `APP_SCHED` 实现异步信号和渲染事件调度，并设计了低功耗睡眠机制（[sleep_mode_enter](file:///e:/EPD-nRF5/main.c#256-268)），支持无线充电唤醒和 NFC 唤醒等。
  - **蓝牙接口通讯**：初始化广播，负责接收和处理空中传送完毕的设置数据、图片流分包或执行蓝牙空中升级（OTA DFU）。

### 2.2 图形界面与显示驱动模块
- **`GUI/`（图形库模块）**
  - 基于知名的 `Adafruit_GFX` 图形库定制优化出的本地图形框架（如 `Adafruit_GFX.c`, `GUI.c`），负责基础线条、形状与文本绘制。
  - **`u8g2_font.c` / `fonts.c`**：负责点阵字体的渲染机制。
  - **`Lunar.c`**：内置了完整的中国农历及节气计算逻辑，供系统刷新并生成日历界面使用。
- **`EPD/`（墨水屏硬件抽象层）**
  - 这里封装了与具体硬件墨水屏驱动控制器（如 `UC81xx`, `SSD16xx` 系列）进行的 SPI 通信及时序指令逻辑。

### 2.3 Web 前端控制工具（上位机）
- **[html/](file:///e:/EPD-nRF5/html/index.html)（Web 蓝牙配置界面）**
  - 该项目不仅是一个单片机固件工程，而且配套完整的 HTML前端（[html/index.html](file:///e:/EPD-nRF5/html/index.html)）。无需安装专门的手机 App，用户只要通过带蓝牙模块的电脑或手机，使用支持 Web Bluetooth 的浏览器打开页面即可对项目进行如下控制：
  - 更新显示内容（提供图片裁剪、文本标注、Dithering/图像抖动算法渲染）。
  - 推送日历布局、切换节假日数据体系。
  - 配置墨水屏的硬件驱动方案以及底层针脚。

### 2.4 本地模拟器与构建工具
- **[emulator.c](file:///e:/EPD-nRF5/emulator.c) / [Makefile](file:///e:/EPD-nRF5/Makefile)**
  - 提供了一个运行在 Windows 的本地模拟器（通过 GDI32 接口调用），可以通过 `gcc` 及 `make` 编译出 `emulator.exe`。
  - **目的**：供开发人员脱离 nRF5 硬件真机在本地进行日历图形排版（GUI）与功能算法（如农历推导算法）的快速迭代与调试验证。

### 2.5 依赖环境与其他系统目录
- **`SDK/`**：内部打包了特定版本的 nRF5 SDK 相关依赖文件。
- **`tools/`**：编译、数据转换、或打包升级包专用的工具链脚本。
- **`docs/`**：存放项目相关的使用说明与开发指南说明，包含 `devices.md` 与 `develop.md` 等指引型文件。

## 3. 设计亮点与技术栈
1. **纯 Web 端交互方案**：上位机采用无需后端依赖的纯前端网页部署，结合现代 Web 蓝牙和网页 Canvas 处理图像抖动渲染，将大量逻辑从单片机转移到前端，极大降低了单片机的存储和算力要求。
2. **灵活的屏幕与针脚映射机制**：通过统一的底层抽象支持市面繁杂尺寸及不同接口映射规则的微雪等各家墨水屏，为 DIY 提供了高度通用的兼容基础。
3. **软硬件协同低功耗策略**：固件层面通过高效定时器、中断状态机和看门狗刷新确保显示完毕后即进入极低功耗待机，在更新界面时再唤醒。

## 4. 下一步开发/探索建议
- 如果您是**前端开发人员**：可以直接在 [html/](file:///e:/EPD-nRF5/html/index.html) 目录通过更新其 canvas 图片处理器或者蓝牙通讯报文来为你的电子相框增加新功能（例如新的日历排版、天气预报支持）。
- 如果您是**固件开发者**：可以关注 [main.c](file:///e:/EPD-nRF5/main.c) 里的事件调度机理，或是 `GUI/` 目录中的渲染及农历算法，考虑为其增加新字体支持或者扩展对更多 MCU 版本的适配。
- 如果您需要**适配新屏幕硬件**：可着重分析 `EPD/` 目录并添加与之对应的墨水屏初始化寄存器刷写操作配置。
