# 0003 — 样式编辑器：无构建单页 + 双端高保真预览 + 墨水屏模式

## 状态

accepted（2026-09-24）

## 决策

样式编辑器为**原生 HTML/JS 单页**（无构建链、不引框架），挂在 `webui.py`（8766）
的新路由 `/style-editor` 下，后端只加少量读写样式的 API。预览在浏览器端用
canvas2d 逐原语镜像 Pillow 的绘制语义（同一字体文件、同一绝对像素坐标系、同样
的渐变/圆角/透明度算法），默认 RGB 显示，可一键切换**墨水屏模式**（JS 复刻
gamma + 四色量化，均为确定性逐像素操作）；另设**真机对照**按钮：后端跑真实
Python 管线出图，与预览叠加比对。样式读写直接落在 ADR 0002 的同一份 JSON 上，
保存前显示变更 diff 供确认，版本与回滚交给 git。

## 被否决的备选

- **React/Vue + 构建链**：一次性内部工具、跑在树莓派上，node 工具链是纯负担。
- **结构近似预览**（位置比例对、颜色大致对）：项目连着修"亮照片底托不可辨"
  "文字过小"这类视觉问题，会骗人的预览等于没有。
- **编辑器自建快照历史**：与 git 形成两套版本控制，多余。

## 后果

- 浏览器与 Pillow 在文本栅格化/抗锯齿上存在细微差异，验收以真机对照目视为准
  （Python↔Python 的迁移验收仍是逐像素一致，见 ADR 0002）。
- JS 侧 gamma/量化实现必须与 Python 保持算法一致，改动终段算法时两边同步。
- 节日模板不在本期范围（v1 只做版式），编辑器架构预留复用。
