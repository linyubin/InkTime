选型策略 · 按照片格局自动排版

渲染时按照片自身的「格局」挑版式。不需要任何新的照片分析——信号全部来自现有管线：choose_gamma 已经算好的亮度估计、YOLO subjects_json、VLM 的 type / caption、库里的 memory_score。逻辑是「加分制打分 + 硬否决 + 确定性平局」，约 40 行 Python，先打分选型、再按所选版式决定裁切避让方向。

④ 决策规则

  1. 兜底回落：亮度估计失败、图像异常 → 直接基线 P01 / L01（对任何照片都成立）；subjects_json 为空不算异常，按「无主体」正常打分。
  2. 硬否决先于得分：会压到主体的版式（P05 压右侧主体、L02 压左侧主体、L06 压上部主体）直接排除；无城市时 P05/L07 整体排除（红章无内容可镌，2026-09-12）；文案超过约 16 汉字 + 2 标点时 P01/P10/P05 排除（这三款对长文案省略号截断，长文案导向支持折行的版式，2026-09-13）——主体不被遮挡优先级最高。
  3. argmax + 确定性平局：取总分最高者；同分时用 hash(照片路径 + 拍摄日期) 挑选——同一照片每次渲染永远得到同一版式（刷屏不跳变），不同照片之间分布均匀、不刻板。
  4. 回落：最高分 ≤ 0（所有候选都被否决或不合适）→ 基线。
  5. 分布校验：上线后统计各版式实际占比，期望每款 10–25%；偏离过多只调分数权重，不动规则结构。2026-09-12 首轮 50 张随机回归：基线合计 64% → 调平后 30%，12/14 款被激活（已按此定稿上方权重）。

import hashlib

def pick_layout(item, ori, white_ratio):
    sub = largest_subject(item["subjects_json"])   # conf>=0.2，person/cat/dog 加权取最大
    S   = sub.area if sub else 0.0                 # 最大主体面积占比
    cx, cy = (sub.cx, sub.cy) if sub else (0.5, 0.5)
    tags = style_tags(item)                        # .zh / .snow / .night / .travel 关键词命中
    sym  = abs(cx - 0.5) < 0.08 and S >= 0.08
    I    = white_ratio                             # choose_gamma 已算好
    hi, lo = I >= 0.55, I <= 0.35

    if ori == "portrait":
        sc = {
          "P01": 1.0 + .3*(not hi and not lo) + .2*(not sub) - .8*(S>=.12 and cy>.6),
          "P03": 1.0*lo + .5*(cx>.35 or cy<.55) + .2*(not sub) - .6*hi,
          "P05": 1.0*hi + .9*tags.zh + .5*(cx<.45) - .3*lo,
          "P08": .9*(cx<.4) + .6*(I>.45 and S<.12) + .3*(item["memory_score"]>=85) - .8*(cx>.6),
          "P10": 1.0*sym + .6*(S>=.12 and abs(cx-.5)<.15) + .4*lo - .4*(cy>.65),
        }
        veto = {"P05": cx > .6 or not city or n_chars > 18,
                "P01": n_chars > 18, "P10": n_chars > 18}
        base = "P01"
    else:
        sc = {
          "L01": 1.0 + .3*(not hi and not lo) + .2*(not sub) - .6*(S>=.12 and cy>.6),
          "L02": .9*(cx>.55 or not sub) + .5*(S<.12) + .5*tags.travel - .9*(cx<.4),
          "L04": .9*lo + .7*sym - .5*hi - .5*(cy>.6),
          "L05": 1.0*hi + .5*(cy>.6) - .3*lo,
          "L06": 1.0*(cy>.55) + .4*(not sub),

        base = "L01"

落地建议

  1. 结构：config.py 增加 TEXT_LAYOUT（竖屏 5 / 横屏 7 个枚举值）；render_daily_photo.py 的 render_image / render_image_landscape 改为按枚举分发到独立小函数，每款一个函数，共享 _get_font / wrap_text_chinese / 毛玻璃 / scrim / 印章五个工具件。
  2. 裁切避让：给 compute_crop_window 增加 top_reserve / left_reserve / right_reserve（现仅 bottom_reserve），L2/L6 等「非底部占位」方案才能不压主体；实色条方案（L05）条身不透明，避让可给 0。
  3. 选型策略：见上方「按照片格局自动选型」章节——用现有管线信号打分选版式，硬否决防压主体，确定性哈希平局（同一照片永远同一版式）。
  4. 验证方式：任选 3–5 款先接进渲染管线出 .bin，实机刷屏后与数码预览对照，重点核对毛玻璃 alpha、小字可读性与红/黄显色。
