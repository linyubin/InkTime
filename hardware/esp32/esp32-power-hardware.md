# ESP32-L 墨水屏设备 · 供电配置与理想二极管改造记录

> 最后更新:2026-10-31
> 适用设备:inktime 墨水屏日历实物(注意:**不是** `esp32/pcb/` 里那张 ESP32-S3 自研板,实物是 GoodDisplay ESP32-L 开发套件)

## 一、整机硬件构成

| 部件 | 型号/说明 |
|---|---|
| 主板 | GoodDisplay **ESP32-L**(ESP32-WROOM-32 模组,CH340G 串口,W25Q16 Flash,GT30L32S4W 字库芯片) |
| 墨水屏驱动转接板 | GoodDisplay **DESPI-C02**(经主板 P5 排针连接,板上电荷泵产生 VGH/VGL 驱动屏幕) |
| 固件 | `esp32/ink-display-wifi-epd/ink-display-wifi-epd.ino` |
| 供电模块 | LM66200 双通道理想二极管模块(双电源 ORing) |
| 电池 | 5V 锂电池组 4000mAh(充放一体:1S 电芯 + 充电管理 + 升压 5V 输出 + 电量显示;输出 XH2.54,充电 DC 头) |
| 外部电源 | USB 5V 适配器(同时负责给电池充电) |

原理图与说明书资料在 NAS:`/mnt/nas/Hermes_ws/gooddisplay/`(ESP32-L_SCH.pdf、DESPI-C02_SCH V1.0.pdf、套件说明书)。

## 二、主板电源架构(ESP32-L)

```
Type-C 5V ──► P2 电源开关(拨ON导通) ──► TEST1(电流测点) ──► F1 保险丝 500mA ──┐
                                                                                ├─ 5V 轨 ──► AMS1117-3.3 ──► 3.3V 轨
P4 "外部电源"排针(引脚1/2 = 5V,同一网络) ────────────────────────────────────┘                │
P9 POWER 排针引脚1 也在 5V 轨上                                                     P3 跳线(PWR_Jump,务必短接)
                                                                                                │
                                                                          R1(0Ω)──► 3.3V_S2 ──► P5 ──► DESPI-C02(墨水屏)
```

要点:

- **全系统唯一电源入口是 5V 轨**;墨水屏驱动板的电从主板 P5 过去,不单独取电。
- P4 六脚:1/2 = 5V(双份)、3/4 = 3.3V、5/6 = GND(双份)。舵机占一组 5V+GND,另一组空余。
- AMS1117-3.3 压差约 1.1V,输入需 ≥4.4V 才能稳出 3.3V;静态电流约 5mA(电池续航的底耗之一)。
- F1 为 500mA 保险丝,舵机堵转可能使其动作(遗留问题,与双电源改造无关)。
- TEST1 是 Type-C 供电路径上的电流测点(无防反接),从它灌电可行但不推荐。

## 三、双电源改造:LM66200 接线定稿

### 目标行为

适配器在场 → 适配器直供;适配器断电 → 微秒级无缝切到电池。

### 模块要点(LM66200,TI 数据手册实锤)

- 输入 1.6–5.5V,单通道 2A,导通电阻 40mΩ;**无限流、无过压、无防反接保护**,怕短路和静电。
- 自动 ORing:**电压高的一路供电**,反向电流阻断;两路几乎等压时优先级不可控(必须人为拉开压差)。
- 引脚(模块丝印):`1`=VIN1、`2`=VIN2、`GND`、`Vout`、`!On`、`Sta`;丝印 "VIN" 印在 1/2 脚下方,第三脚是 GND,别认错。
- **!On 低电平使能**:接 GND = 开机;接高/悬空 = 关机(Vout 变 Hi-Z,万用表会读到漏电流幻影电压)。
- **Sta 开漏状态输出**:VIN1 供电时高、VIN2 供电时低;读 MCU 需外部上拉(只能上拉到 3.3V,ESP32 IO 耐压 3.6V);无上拉则恒为 0,属正常。
- 切换时间 μs 级;前提是两路输入在切换瞬间都有电(见"已知问题")。

### 接线(当前实际)

```
适配器 5V ──┬──► 电池 pack 充电口(DC头,保持不动)
            └──► LM66200 "2"(VIN2)
电池 pack 5V 输出(XH2.54) ──[串肖特基 1N5819/SS34,拉到≈4.7V]──► LM66200 "1"(VIN1)
LM66200 Vout ──► USB线红线(VBUS)──► Type-C公头 ──► 主板 Type-C 口
LM66200 GND  ──► USB线黑线 ──► Type-C(与电池、适配器、主板四方共地)
LM66200 !On  ──► GND(常开)
主板:P2 电源开关拨 ON;舵机维持 P4 5V 不动
```

- 电池串肖特基的目的:电池恒低于适配器约 0.3V,保证"适配器优先";断电切换后 4.7V 仍满足 AMS1117 需求。
- P2 拨 ON 的原因:Vout 从 Type-C 进板必须经过该开关;此路径含 F1 保险丝,反而比走 P4 更规范。
- 副作用:插电脑调试时 LM66200 的 5V 会经 Type-C 反灌一点进 USB 口(主板无防倒灌器件),一般无害;介意就在调试时拔掉 Vout 输出线。CH340 靠 3.3V 轨供电,烧录/串口不受影响。
- Vout 处建议并 10µF 电容(模块板载仅 1µF);当前未装——主板 Type-C 进线处已有 C1 10µF/16V 兜底,常规工况够用。风险窗口仅"舵机动作瞬间拔适配器"。

### 可选扩展(未实施)

Sta 经 10kΩ 上拉到 3.3V(P4 的 3.3V 脚)后接 P8 排针 IO34/IO35(纯输入脚),固件可上报当前供电来源(高=电池,低=适配器)。

## 四、当前状态(2026-10-31)

- ✅ LM66200 模块本体已调通:空板验收 VIN1≈电池电压、Vout≈VIN1、!On=0V。
- ❌ **整机未闭环:拔掉适配器主板仍会重启。**
- 根因已定位:**5V 电池 pack 在"充电中→纯放电"交接时,输出会断若干毫秒**(该 pack 板内升压的模式切换间隙)。证据:未加理想二极管之前,拔插适配器就重启;LM66200 的 VIN1 恰是该 pack 输出,源自己断电则二极管无源可导。
- 结论:**该 pack 的 5V 输出端口不能作常备电源**;4000mAh 电芯本身是好的。

## 五、待办(修复方向,二选一)

1. **路线 A(保留 pack,推荐)**:开壳从保护板 B+/B− 引出电芯电压 → 常开升压模块(输出调 4.7–4.8V)→ VIN1。pack 的充电口与电量显示照常;原 5V 输出线退役。注意:引线先镀锡快焊、防 B± 短路、接模块前先用电压档确认正负。
2. **路线 B(三件套替换)**:带保护板 1S 电芯 + TP4056 充电板 + 常开升压板(调 4.7V),约 20 元;pack 退役。
3. 不建议再买"标称无缝 UPS"的成品模块,容易踩同一个坑(标称 UPS、实为毫秒级交接)。

### 验收清单(修复后逐项过)

- [ ] 插适配器:主板 Type-C 处 ≈5V;
- [ ] 拔适配器:Vout 无扰动落到 ≈4.7V,主板不重启;
- [ ] 最恶劣工况:舵机来回扫动中反复拔插适配器 20–30 次,无一次重启;
- [ ] 串口确认启动原因 `esp_reset_reason()` 非 `ESP_RST_BROWNOUT`(必要时在 device_log 中加启动原因日志)。

## 六、排障记录(踩坑存档)

1. **模块焊盘不可只看丝印猜测,通电后逐脚对 GND 量电压验收**(期望:VIN1≈输入、Vout≈输入、!On=0、GND=0)。
2. **万用表表笔插反**(红笔插在 COM)导致全部读数符号颠倒,一度误判为"电池反接烧芯片"。教训:电源类测量先锚定极性——量已知电源(如电池本体)确认符号,再测待测点;蜂鸣档只验证通断,不验证极性。
3. **第一颗 LM66200 已损坏,判据与过程**:空载下 Vout 恒为 2.24V(健康芯片应≈VIN);断电测 Vout↔GND 电阻稳定在 138Ω(健康应为几十 kΩ 以上且呈电容充电特性);两者互相印证功率管半击穿(内阻≈140Ω)。该芯片无限流无限过流保护,Vout 对地短一次即可打坏,替换的新模块先做空板电阻+六焊盘验收再接入系统。
4. **新模块验收特征**:不同电阻档读数不同(9k@20K 档 / 50k@200K 档)= 芯片内部半导体网络+LED 通路,正常;像坏模块那样各档位钉死一个纯电阻值才是病态。
5. **"半吊子电压"(1V 上下)的典型含义**:芯片处于关断(!On 悬空/接错)时 Vout 呈高阻,万用表读到的是 nA 级漏电流折算的幻影电压,数值随机且随接入源变化——不是"电压不准",是没导通。

## 七、遗留小问题(与双电源无关)

- AMS1117 静态电流 ~5mA + 升压/电池管理底耗:整系统待机常载约 10mA 级;在意续航可换低静态电流 LDO(如 HT7333)。
- 舵机与主板共用 5V 轨且 F1 仅 500mA:舵机堵转可能触发保险丝。
- 仓库内 `esp32/pcb/`(ESP32-S3-InkDisplay,TP4056+MIC5219)与 `esp32/ink-display-wifi-epd/schematic_text.txt`(ESP32-L 原理图文本)是两个不同时期的板子;实物是后者(ESP32-L)。
